# Intervexa brand

Pronunciation: in-ter-VEK-sa. Working positioning: software integration intelligence for engineering teams. Tagline: **Every change. Every interaction. Verified.**

The original glyph connects branching paths through a rotated verification node. `public/brand/intervexa-mark.svg` is the color master; `scripts/brand.py` generates consistent variants. Dark and light lockups use the same geometry; mono and reversed white variants are available. SVGs contain no external resources.

Colors: graphite #10121B, indigo #818CF8, violet #C084FC, neutral #F9FAFB, slate #94A3B8. Use system Inter/Geist where installed, with Arial/sans-serif fallback; do not require a network font to render. UI uses a restrained system sans stack and monospace for revisions/logs.

Clear space: at least one quarter of the mark width on each side. Minimum mark size: 24 px; lockup width: 128 px. Use white lettering on graphite, graphite lettering on light surfaces, and mono in single-ink contexts. Do not stretch, add glows, rotate the complete mark, change the lettering, or place it on busy backgrounds.

Intervexa is a proposed working brand. No trademark, domain, or social-handle clearance has been performed. The owner must complete those checks before public launch.
